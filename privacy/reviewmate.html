개인정보 처리방침

체험단짝

시행일: 2026년 10월 8일 · 최종 수정일: 2026년 10월 8일

체험단짝(이하 "앱")은 사용자의 개인정보를 소중히 여기며, 개인정보 보호와 관련한 관계 법령을 준수합니다. 본 개인정보 처리방침은 앱이 사용자 정보를 어떻게 취급하는지 설명합니다.

  • 회원가입이 없고 이름·이메일·전화번호를 받지 않습니다.
  • 체험단 기록 등 입력한 모든 데이터는 기기 안에만 저장됩니다.
  • 광고를 위해 Google AdMob이 기기 식별자 등을 수집합니다.

1. 수집하는 개인정보

앱 자체는 사용자를 식별할 수 있는 정보를 수집하지 않습니다.

회원가입과 로그인 절차가 없으며, 이름·이메일 주소·전화번호를 요구하지 않습니다. 위치 권한도 요청하지 않습니다. 다만 앱 내 광고를 제공하기 위해 Google AdMob이 기기 광고 식별자 등 일부 정보를 수집합니다. 수집 항목과 목적은 아래 5항에 표로 정리했습니다.

2. 사용자가 입력한 데이터의 저장 및 처리

사용자가 앱에 입력하는 모든 데이터는 다음과 같이 처리됩니다.

저장되는 데이터의 종류

  • 체험단 기록 (제품·업체명, 사이트 이름, 종류, 상태, 혜택 금액, 제공 내역, 참여 조건, 링크, 메모)
  • 일정 (발표일, 체험 기간, 리뷰 마감일, 참여일, 완료일)
  • 직접 만든 '내 사이트' 목록
  • 앱 환경 설정 (테마, 글꼴, 알림 설정, 앱 잠금 사용 여부)

저장 위치

  • 위 데이터는 전적으로 사용자 기기 내부에만 저장됩니다.
  • 개발자가 운영하는 서버가 없으며, 개발자는 사용자의 데이터에 접근할 수 없습니다.
  • 제3자에게 제공되거나 판매되지 않습니다.
  • 저장 폴더에는 iOS의 파일 보호 등급(Complete)이 적용되어, 기기가 잠겨 있는 동안에는 읽을 수 없습니다.

3. 내보내기 · 백업 및 복원

사용자는 앱 내 기능을 통해 데이터를 파일로 내보낼 수 있습니다. (CSV 내보내기, 백업하기)

  • 백업 파일과 CSV 파일은 사용자가 직접 선택한 위치(파일 앱, iCloud Drive 등)에만 저장되며, 개발자나 외부 서버로 전송되지 않습니다.
  • 백업 파일에는 앱에 입력한 체험단 기록이 그대로 담기므로 사용자가 안전한 곳에 보관해야 합니다.
  • 앱 잠금 설정은 백업에 포함되지 않습니다. 새 기기에서는 직접 다시 켜야 합니다.
  • 파일의 관리와 보안은 사용자 본인의 책임 하에 있습니다. 개발자는 이 파일에 접근하거나 수집하지 않습니다.

4. 앱 권한

앱은 다음 권한을 요청할 수 있으며, 각 권한은 해당 기능 제공 목적으로만 사용됩니다.

권한사용 목적필수 여부
알림발표일, 참여일, 리뷰 마감 하루 전·당일 알림 전송선택 (거부해도 앱 사용 가능)
Face ID / Touch ID앱 잠금 기능 제공선택
추적 허용(ATT)맞춤형 광고 제공선택 (거부해도 앱 사용 가능)

알림은 기기 안에서 예약되며 외부 서버를 거치지 않습니다. 생체인증 정보는 Apple의 시스템 수준에서 처리되며, 앱은 사용자의 생체 정보를 저장하거나 접근하지 않습니다. 앱이 받는 것은 인증 성공 여부뿐입니다.

5. 광고 및 제3자 정보 수집

본 앱은 무료 제공을 위해 Google의 AdMob 광고를 사용합니다. 유럽 등 일부 지역에서는 광고를 표시하기 전에 Google의 사용자 메시징 플랫폼(UMP)을 통해 동의를 먼저 받습니다. iOS에서는 맞춤형 광고를 위해 추적 허용(ATT)을 별도로 요청하며, 거부해도 앱의 모든 기능을 그대로 쓸 수 있습니다.

이 정보는 광고를 표시하고 부정 클릭을 걸러내는 데 쓰입니다. 개발자는 이 정보를 열람하거나 내려받지 않으며, Google이 제공하는 총계 형태의 수익 통계만 확인합니다. 사용자가 앱에 입력한 체험단 기록·혜택 금액·메모는 광고 제공자를 포함한 누구에게도 제공되지 않습니다. 광고 요청에 체험단 내용이 키워드나 타기팅 정보로 실리지 않습니다.

  • Google 개인정보처리방침: policies.google.com/privacy
  • Google이 광고 파트너로서 데이터를 이용하는 방식: policies.google.com/technologies/partner-sites

맞춤형 광고 끄는 방법

  • 설정 → 개인정보 보호 및 보안 → 추적 에서 앱별로 끌 수 있습니다.
  • 설정 → 개인정보 보호 및 보안 → Apple 광고 → 맞춤형 광고 를 꺼도 됩니다.
  • 끄더라도 광고 자체는 계속 표시되며, 이용자와 관련성이 낮은 광고로 바뀝니다.

6. 아동의 개인정보

본 앱은 만 14세 미만 아동을 주 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

7. 데이터 삭제

사용자는 다음 방법으로 데이터를 삭제할 수 있습니다.

  • 개별 기록 삭제 : 체험단 목록에서 항목을 왼쪽으로 밀어 삭제
  • 사이트 목록 정리 : 설정 → 사이트 관리 에서 밀어서 삭제
  • 기기에서 앱을 삭제 (앱 삭제 시 기기에 저장된 데이터도 함께 삭제됩니다)

앱을 삭제하면 기기에 저장된 데이터는 복구할 수 없으므로, 삭제 전 백업 기능을 이용해주시기 바랍니다.

8. 개인정보 처리방침의 변경

본 개인정보 처리방침은 법령 변경, 앱 기능 추가 등의 사유로 변경될 수 있습니다. 중요한 변경 사항이 있을 경우 앱 업데이트 또는 본 페이지를 통해 공지합니다.
