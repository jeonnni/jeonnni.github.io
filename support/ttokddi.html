자주 묻는 질문

시간표에 직접 글자를 못 적어요. 왜 그런가요?

타임박싱 플래너는 우선순위 또는 브레인덤프에 적어둔 항목을 시간표로 옮기는 방식으로 동작합니다. 항목을 길게 눌러 원하는 시간대로 드래그해 배치해주세요.

캘린더 연동이 안 돼요.

설정 → 캘린더 연동에서 원하는 캘린더를 선택하고 권한을 허용했는지 확인해주세요. 아이폰 설정 → 개인정보 보호 및 보안 → 캘린더에서도 앱 권한이 켜져 있는지 확인 부탁드립니다.

알림이 안 와요.

아이폰 설정 → 알림 → 똑띠 플래너에서 알림이 켜져 있는지 확인해주세요. 앱 내에서는 일정마다 알림 주기를 개별 설정할 수 있습니다.

테마는 어디서 바꾸나요?

설정 → 테마에서 손글씨 테마와 일반 폰트 테마 중 선택할 수 있습니다.

기기를 바꾸면 데이터가 유지되나요?

현재 버전은 데이터가 기기에만 저장됩니다. 기기 변경 시 데이터가 이전되지 않으니 참고 부탁드립니다.

광고가 나오는데 끌 수 있나요?

앱은 무료로 제공되며 배너/전면 광고로 운영됩니다. 현재 광고 제거 옵션은 제공하지 않습니다.

캘린더에 일정이 중복으로 생겨요.

시간표 블록 수정 후 기존 캘린더 이벤트가 남아있는 경우 발생할 수 있습니다. 문의 주시면 빠르게 확인해드릴게요.
