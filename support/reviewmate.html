자주 묻는 질문

데이터는 어디에 저장되나요?

입력하신 모든 체험단 기록과 설정은 사용자 기기 내부에만 저장됩니다. 외부 서버로 전송되지 않으며, 개발자를 포함한 제3자가 데이터를 열람할 수 없습니다.

기기를 바꾸면 데이터가 사라지나요?

앱 내 백업 기능을 이용해 데이터를 파일로 내보낸 뒤, 새 기기에서 복원할 수 있습니다. 앱을 삭제하기 전에 반드시 백업해두시기를 권장합니다.

백업은 어떻게 하나요?

설정 → 백업 에서 '백업하기'를 누르면 현재 데이터를 파일 하나로 내보낼 수 있습니다. 내보낸 파일은 파일 앱이나 클라우드 저장소에 보관해두세요. 복원할 때는 같은 화면에서 '복원하기'를 누르고 저장해둔 파일을 선택하면 됩니다.

백업에는 체험단 기록과 '내 사이트' 목록, 테마·글꼴·알림 설정이 담깁니다. 앱 잠금 설정은 담기지 않으니 새 기기에서 다시 켜주세요. 백업 파일에는 기록이 그대로 들어 있으므로 안전한 곳에 보관해주세요.

잘못 복원했어요

설정 → 백업 → '복원 직전으로 되돌리기' 를 누르면 복원하기 직전의 기록으로 돌아갑니다. 복원한 뒤에 추가하거나 고친 내용은 사라집니다.

사이트 칩이 하나도 없어요

처음에는 비어 있습니다. 자주 쓰는 체험단 사이트는 사람마다 다르기 때문에 직접 담도록 해두었습니다. 입력 화면의 '+ 추가' 칩을 누르거나, 사이트 칸에 이름을 적고 저장하면 목록에 자동으로 들어갑니다. 설정 → 사이트 관리 에서 순서를 바꾸거나 이름을 고칠 수도 있습니다.

사이트 이름을 바꾸면 기존 기록은요?

설정 → 사이트 관리 에서 이름을 바꾸면 그 사이트로 적어 둔 기존 기록의 이름도 함께 바뀝니다. 절약 탭의 사이트별 합계가 갈라지지 않도록 하기 위해서입니다. 목록에서 지우기만 하면 기존 기록의 이름은 그대로 남습니다.

알림이 오지 않아요

아이폰 설정 앱에서 알림 권한이 허용되어 있는지 확인해주세요.

설정 → 알림 → 체험단짝 → 알림 허용

앱에서는 설정 → 알림 → '일정 알림'이 켜져 있는지 확인해주세요. 신청한 건은 발표일에, 선정된 건은 참여일과 리뷰 마감 하루 전·당일에 알려드립니다. 날짜를 비워두면 알림을 보낼 기준이 없어 알림이 가지 않습니다.

날짜를 모를 때는 어떻게 하나요?

모든 날짜는 비워둘 수 있습니다. 미정이거나 상시모집이면 그냥 두세요. 나중에 정해지면 그때 넣으면 됩니다.

체험 기간은 어떻게 고르나요?

'체험 기간' 줄의 '추가'를 누르면 달력이 뜹니다. 처음 누른 날이 시작일, 다음에 누른 날이 종료일입니다. 같은 날을 두 번 누르면 하루짜리 기간이 됩니다. 체험 종료일을 넣으면 리뷰 마감일이 같은 날로 자동으로 채워집니다.

아낀 금액은 어떻게 계산되나요?

상태를 '완료'로 바꾼 체험단의 혜택 금액만 더합니다. 선정만 된 건은 '받을 예정'으로 따로 보여주고 합계에는 넣지 않습니다.

앱을 잠글 수 있나요?

Face ID 또는 Touch ID를 이용한 잠금 기능을 제공합니다. 설정 → 보안 → Face ID 잠금 에서 켤 수 있습니다. 켜두면 앱을 열 때마다 인증을 받고, 앱 전환 화면에서도 내용이 보이지 않습니다.

테마와 글꼴을 바꿀 수 있나요?

설정 → 테마 에서 크림·초코 두 가지를, 글꼴 에서 네 가지를 고를 수 있습니다. 고르면 바로 앱 전체에 적용되고 홈 화면 아이콘도 함께 바뀝니다. 기기의 다크 모드 설정과는 상관없이 고른 테마대로 보입니다.

엑셀로 내보낼 수 있나요?

네, 설정 → 백업 → CSV 내보내기 를 이용해주세요. 엑셀에서 바로 열 수 있습니다.

광고를 없앨 수 있나요?

현재 광고 제거 상품은 없습니다. 앱을 무료로 제공하기 위해 Google AdMob 광고를 사용하고 있습니다.

버그 신고 및 기능 제안

사용하시면서 불편한 점이나 있었으면 하는 기능이 있다면 언제든 이메일로 알려주세요. 사용자분들의 의견을 반영해 앱을 꾸준히 개선해나가고 있습니다.
