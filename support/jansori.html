자주 묻는 질문

데이터는 어디에 저장되나요?

입력하신 모든 거래 내역과 설정은 사용자 기기 내부에만 저장됩니다. 외부 서버로 전송되지 않으며, 개발자를 포함한 제3자가 데이터를 열람할 수 없습니다.

기기를 바꾸면 데이터가 사라지나요?

앱 내 백업 기능을 이용해 데이터를 파일로 내보낸 뒤, 새 기기에서 복원할 수 있습니다. 앱을 삭제하기 전에 반드시 백업해두시기를 권장합니다.

백업은 어떻게 하나요?

더보기 → 백업 · 복원 에서 '백업하기'를 누르면 현재 데이터를 파일로 내보낼 수 있습니다. 내보낸 파일은 파일 앱이나 클라우드 저장소에 보관해두세요. 복원할 때는 같은 화면에서 저장해둔 백업 파일을 선택하면 됩니다.

정기적으로 백업해두시면 예기치 못한 상황에서도 데이터를 안전하게 지킬 수 있습니다.

알림이 오지 않아요

아이폰 설정 앱에서 알림 권한이 허용되어 있는지 확인해주세요.

설정 → 알림 → 잔소리 가계부 → 알림 허용

앱에서는 더보기 → 설정 에서 아래 항목이 켜져 있는지 확인해주세요. (매일 속담 알림, 잔소리 켜기, 점수 상승 칭찬 알림)

카테고리를 추가하거나 수정할 수 있나요?

네, 가능합니다. 더보기 → 카테고리 관리 에서 대분류와 서브카테고리를 자유롭게 추가, 수정, 삭제할 수 있습니다.

적금이나 카드값은 어떻게 기록하나요?

입력 화면에서 '이체'를 고르세요. 쓴 돈이 아니라 옮긴 돈이므로 수입·지출 합계와 예산에 반영되지 않습니다. 메모에 용도를 적어두시면 나중에 알아보기 쉽습니다.

홈 화면 잔액이 수입에서 지출을 뺀 값과 다릅니다

'지난달 잔액 이월'이 켜져 있으면 지난달까지 남은 돈이 함께 더해집니다. 더보기 → 설정 → 지난달 잔액 이월 에서 끌 수 있으며, 처음에는 꺼져 있습니다.

예산을 초과했는데 알림이 오지 않아요

먼저 예산 한도가 정해져 있는지 확인해주세요. 한도를 정하지 않으면 넘길 기준이 없어 알림이 가지 않습니다. (더보기 → 예산 설정)

그다음 더보기 → 설정 에서 '잔소리 켜기'가 켜져 있는지, 아이폰 자체의 알림 권한이 허용되어 있는지 확인해주세요.

데이터를 엑셀로 내보낼 수 있나요?

네, 거래 내역을 XLSX 또는 CSV 형식으로 내보낼 수 있습니다. 더보기 → 내보내기 (Excel/CSV) 를 이용해주세요.

앱을 잠글 수 있나요?

Face ID 또는 Touch ID를 이용한 생체인증 잠금 기능을 제공합니다. 더보기 → 설정 → Face ID / 암호 잠금 에서 켤 수 있습니다.

광고를 없앨 수 있나요?

현재 광고 제거 상품은 없습니다. 앱을 무료로 제공하기 위해 Google AdMob 광고를 사용하고 있습니다.

버그 신고 및 기능 제안

사용하시면서 불편한 점이나 있었으면 하는 기능이 있다면 언제든 이메일로 알려주세요. 사용자분들의 의견을 반영해 앱을 꾸준히 개선해나가고 있습니다.

개인정보 처리방침

가계부에 입력한 거래 내역·금액·메모는 기기 안에만 저장되며 외부로 전송되지 않습니다. 앱 내 광고 제공을 위해 Google AdMob이 일부 정보를 수집합니다. 자세한 내용은 개인정보 처리방침 페이지를 참고해주세요.
